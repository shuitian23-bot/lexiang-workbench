# 联想商城 SPU 商品数据包

由 84 个 SKU 合并为 50 个 SPU。相同“简短商品名称”的 SKU 归入同一 SPU。

每个 SPU 根目录包含汇总文案和代表图片；`配置/` 子目录保留各 SKU 的独立文案、白底图和详情图。

分类SPU数量：{"笔记本": 12, "台式机": 5, "手机": 6, "平板": 6, "选件": 11, "服务": 10}

## 共享资源规则

同一 SPU 下的所有 SKU 共用 SPU 根目录的 `商品文案.md`、`白底图.jpg` 和 `详情图.jpg`。各 SKU 的配置、价格和来源信息统一保存在 `manifest.json` 的 `configurations` 中。
