# 联想乐享 PC 5.0 模板导航 P0

直接打开最外层 `index.html`。它就是规范中的 `home-fullscreen-dialog-template.html` 首页模板；其余四个规范模板也放在最外层。

顶部导航对应关系：

- 首页：`index.html`（源自 `home-fullscreen-dialog-template.html`）
- 个人及家庭：`shop-chat/index.html`
- 中小企业：`b-chat/index.html`
- 政教及大企业：`biz-chat/index.html`
- 品牌：`brand/index.html`

五个外层页面保持规范模板结构，共用 `assets/frontend/js/core/p0-root-nav.js`，顶部频道导航可在五个页面之间互相跳转，当前频道自动高亮，点击品牌标识返回 `index.html`。

五个页面共用 `lexiang.conversation.v1` 会话快照。切换频道时，导航脚本会直接读取当前可见的用户消息与联想乐享回复，立即写入共享快照，再由目标页面恢复；返回首页时，共享会话会导入全屏对话线程继续显示。直接双击 HTML 时，导航脚本还会通过同标签页临时桥接快照，避免浏览器把不同 `file://` 页面存储隔离。
频道页处于左右分屏时，以当前分屏中的完整多轮为权威数据，隐藏的全屏线程不得参与覆盖；只有首页真正处于全屏对话态时才保存全屏线程。因此“解决方案多轮→切换顶部频道→再切回”会保留所有对话和结果卡，不会回退成首轮。

右侧顶部标签严格执行 PC 5.0 `v0.14.30-stage` 规范：首次只有 1 个真实右侧页面时隐藏标签栏；第 2 个页面生成后同时显示 2 个真实标签；更多页面保持一页一标签；关闭到只剩 1 页时再次隐藏标签栏但保留该页面。标签按稳定页面 ID 去重，首页不会因分屏复用商城状态错误生成“个人及家庭”标签，也不使用频道、站点或占位标签凑数。

多标签显示时，首页、个人及家庭、中小企业、政教及大企业、品牌统一使用首页左右分屏现有样式计算得到的 `43px` 顶部标签栏高度。标签始终保持单行，数量增加时横向滚动，不允许换行撑高或因频道样式追加底部间距。
当“个人及家庭”存在可见多标签时，标签栏与下方 Hero/频道内容的垂直间距固定为 `18px`，与中小企业、政教及大企业保持一致；该规则不叠加到单页无标签和分类栏吸顶状态。

右侧页面标签的内边距统一为 `padding: 4px 10px 4px 10px !important;`，不再使用左右不对称的旧值。

标签内关闭叉号按钮统一使用 `padding: 0 !important;`，不得继承模板中的 `2px 4px` 或其他额外内边距。

根首页右侧页面注册表不得出现 `个人及家庭` 或任何 `site:*` 频道占位页。无论来自方案选择、商品选择、历史会话恢复、缓存恢复、重复点击或频道状态复用，每次标签栏渲染前都必须按首页真实路由清除合成频道页；首页只登记用户实际打开的结果页面。

首页、中小企业、政教及大企业等所有右屏多标签使用同一顶部高度基准：标签栏可见时，右侧内容容器 `padding-top` 必须归零，顶部 `18px` 安全间距只允许由固定 `43px` 高的标签栏自身提供，禁止频道容器再次叠加间距造成整体下沉。

首页、个人及家庭、中小企业、政教及大企业、品牌左侧必须使用同一个“联想乐享”智能体内核。同一问题在任一入口都必须经过相同意图识别、知识、官方模型、技能链、回答生成、客服能力和结果卡逻辑，并得到一致回答；频道只能决定右侧默认内容、货盘和导航身份，不得替换智能体人格、限制任务链、禁用能力或改写回答范围。左侧快捷能力、欢迎问题和输入提示统一继承首页配置。

统一智能体规则同时覆盖页面入口与布局状态：首页全屏态、首页左右分屏态、个人及家庭、中小企业、政教及大企业、品牌频道态不得为同一 query 设置不同快捷回答。以“解决方案”为验收样例，所有状态必须输出相同三段正文、相同“查看全集解决方案”结果卡，并严格按“正文逐字完成 → 结果卡出现 → 右侧全集页打开”的顺序执行；禁止频道态用一行操作确认文案替代完整回答。

智能体处于正文生成、任务执行或结果生成状态时，统一隐藏商品与方案的“乐享预判 / 乐享建议你问问”悬浮推荐卡，并立即清除已打开卡片；生成完成后仅恢复正常悬停触发能力，不自动重现上一张预判卡。

商品卡与方案卡统一常驻显示右上角勾选控件，点击后共用引用到对话输入框的选中/取消选中逻辑。

从个人及家庭、中小企业、政教及大企业或品牌频道展开全屏后，“新建对话”收起回当前频道的新对话分屏态。全屏历史结果卡再次点击时，复用同一收起过渡并按稳定 Tab ID 恢复原右侧内容，不离开助手左右结构。

## 前端文件结构

页面已经从单文件 POC 拆分为 DOM、CSS、JS 三层：

- 五个 `index.html`：只保留页面 DOM、静态 `<base>`、外部 CSS/JS 引用。
- `assets/frontend/css/`：全部样式；内部按 `core`、`shared`、`pages/<page>` 分类。
- `assets/frontend/js/`：全部脚本；内部按 `core`、`shared`、`pages/<page>` 分类。

`home`、`shop`、`smb`、`biz`、`brand` 是五个页面资源命名空间。所有 CSS/JS 统一收口在 `assets/frontend/`，公共资源按内容哈希命名，确保相同代码只保留一份且不改变原加载顺序。
