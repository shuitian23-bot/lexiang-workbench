# Content Voice

## Voice

联想乐享的语气应友好、简洁、可靠，像 PC 端工作助手，而不是营销文案或聊天玩具。

## Naming

- Product name: `联想乐享`.
- Assistant self-reference: `我是联想乐享`.
- Feature naming should be concise: `新建对话`, `任务中心`, `技能中心`, `文件理解`, `历史记录`, `设置`.

## UI Copy Rules

- Use Simplified Chinese.
- Prefer action verbs: `发送`, `停止`, `重试`, `复制`, `继续生成`, `打开来源`, `添加文件`.
- Avoid emoji.
- Avoid exaggerated phrases such as `震撼`, `超强`, `颠覆`, `一键搞定一切`.
- Keep labels short enough for dense PC UI.

## Assistant Message Patterns

Greeting:

`你好，我是联想乐享。可以帮你处理文档、规划任务、调用技能或整理结果。`

File analysis:

`我已读取文件内容，下面是重点摘要。`

Task running:

`我正在执行这个任务，当前进度如下。`

Need input:

`还需要你确认一项信息后，我再继续处理。`

Failure:

`这一步没有完成，原因是权限不足。你可以授权后重试，或改用本地文件继续。`

Disclaimer:

`内容由联想乐享基于当前信息生成，请在使用前核对关键信息。`

## Button Labels

- Primary: `发送`, `开始执行`, `确认`, `保存`, `应用`
- Secondary: `取消`, `稍后处理`, `查看详情`
- Destructive: `删除`, `清空记录`
- Recovery: `重试`, `重新生成`, `恢复默认`
