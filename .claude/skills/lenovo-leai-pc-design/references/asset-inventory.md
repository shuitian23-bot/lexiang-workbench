## Templates

- `assets/templates/design-framework.html`: reusable PC dialog shopping-guide page framework. Use it when creating a Lenovo Lexiang PC dialog home, product discovery, or shopping-guide prototype. It includes the official commerce top nav, assistant panel, scrollable product area, bottom composer, prompt dots hover menu, `更多` menu, account menu, edge-based assistant resize, and `换位` left/right swap behavior.
- `assets/templates/design-system-complete.html`: complete HTML design-system gallery. Use it when a task needs the full visual and interaction standard covering colors, typography, spacing, buttons, icons, forms, menus, cards, composer, messages, states, tables, modals, hover, focus, disabled, and AI disclaimers.
- `assets/templates/design-framework-standard-interactive.html`: canonical reusable design-system interaction template based on `design-framework.html`. Use it when a task needs a standard interactive file that demonstrates tokens, top navigation, assistant states, floating menus, composer, collapse/restore, swap, and status switching.
- `assets/templates/lexiang-plus-design-framework-interactive.html`: 乐享+ canonical reusable interaction template based strictly on `design-framework.html`. Use it when a task needs a 乐享+ standard template file with the same tokens, top navigation, assistant states, floating menus, composer, collapse/restore, swap, and status switching.
- `assets/templates/design-framework-interactive.html`: equivalent earlier interaction template entry.
