## 3. Agent 三层信息结构

### 顶部：本轮处理过程

保持逐项彩色 Thinking 状态卡，不能用底部活动行替代。默认收起完整历史，至多显示三张当前活动卡；用户展开选择在实时步骤移交本轮历史后保留，新 query 独立。各卡详情独立展开；语义色表达进行、完成、待确认、失败，不能只有颜色区别。图标底座24px、图标15px、内距9px 10px、圆角与间距8px、标题说明12px、状态11px；摘要图标18px、展开按钮24px。减少动态效果下禁用入场和动态点。

仅显示已到达的公开步骤，不展示私有思维链、原始协议或内部命令参数。工具返回更新原等待项；完成、失败、停止必须终止未完成状态。可选追问不当作阻塞；授权等待不当作已执行。

### 中部：一轮 query 的回答

同一 query 一个外围回答容器，内部保留说明、授权任务、报告、最终结果及可执行动作；只保留一个最新回答时间与一组反馈。用户消息时间独立，初始无 query 归属消息不强行合并。分组属于视图，不改变消息存储、任务身份、授权范围、事件及报告下载/打开合同。必要授权始终可见，不被过程折叠隐藏。结果区分完成、部分失败、失败、主动停止。空回复、只有工具协议的回复不得呈现成功或虚构报告。

### 底部：此刻仍在做什么

最新输出末尾仅一行当前公开动作，正常文档流布局，不固定于输入框、不堆积历史。16px线性图标，20px画布、1.75描边、圆端圆角；文字14px/400/20px，图文间距8px。无卡片、底座、状态点、按钮、背景或扫光。图标与上方状态卡/回答卡的外侧左边缘对齐，横向内距0。中性灰并支持暗色、强制颜色；长标题单行省略但保留完整可访问文本和 title。

十类动作：search/read/terminal/skill/analysis/write/network/wait/export/navigate。只依据公开事件标题和种类，工具动作优先于同时存在的 Thinking；未知工具用通用工具图标，仅有等待信息用等待图标。不从用户问题、计时器、私有思考或参数猜测细分进度。普通请求、有效授权执行及逐字输出分别驱动状态；完成、失败、停止后撤下，静态历史不得复活活动行。

用户向上阅读不强制拉底；新轮发送恢复跟随。失败恢复仅将问题放回输入框，由用户发送，不自动重放写操作或伪造附件恢复。开发演示必须明确标识模拟，使用真实消息生命周期；正式构建禁用演示入口。
