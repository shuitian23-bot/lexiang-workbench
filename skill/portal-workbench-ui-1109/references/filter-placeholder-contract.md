# 筛选区框内提示合同（2026-11-09 用户确认）

## 适用范围与优先级

用于门户工作台 PM 新增页面、UI 原型和研发中的列表、看板、配置列表的查询/筛选区域，包含展开后的高级条件。本合同覆盖历史“筛选标签持久显示”“多个日期必须显示外部标签”以及默认28px密集筛选的冲突规则；业务录入表单、弹窗/抽屉编辑表单、Skill 创建、权限申请中的上置标签保持原合同。

已确认消费者：GEO整体数据概览的意图选择、协议采购单管理、商品视频配置、活动积分配置、活动积分明细、评价总结、辅助生成的指定筛选区。权限管理既有审批列表暂不迁移；这不是新增其他业务筛选页继续使用上置标签的理由。不自动批量改造其他历史页面，不改字段、权限、条件值、查询/重置或实时筛选的业务语义。

## 可见排版

- 不在输入框、下拉框和日期框上方另排字段标题；原型的重点是字段信息在框内，不只是背景、描边和圆角。
- 输入为空时，用明确底文表达字段，例如“商品名称”“商品编号”“采购单号、客户、协议名称、负责人”。已有值按正常输入显示；不添加浮动标题。
- 单选/可搜索选择框在闭合态持续显示“字段名 - 当前选项”，默认统一“状态 - 全部”“商城 - 全部”“累计方式 - 全部”。不得写成“状态 - 全部状态”等重复文案。实际 option value、搜索文本和筛选条件不能加展示前缀；多选保持现有选中/移除合同，在控件内表达字段和选择摘要。
- 日期未选时，在框内显示“开始日期 / 结束日期”；有多组日期时显示“付款开始日期 / 付款结束日期”等独立明确名称。获得焦点后可显示原生日期编辑段；选中后显示真实日期。保留日历图标、键盘输入、日历选择和日期校验，不能简单依赖原生 date 的 placeholder 属性。
- 条件在同一网格行中对齐；查询、重置、高级筛选按既有流程排布，拥挤时整组换行。不为适配单个截图固定页面宽度或强制全部条件挤在一行。
- 常规筛选控件和查询/重置按钮为36px高、13px字、8px圆角，文本水平内距12px；白底、细边框、次级占位色、共享focus ring。选择箭头和日期图标保留右侧空间。不要被继承全局CSS改为10px圆角或28px高度。
- 筛选字段间距12px；遵循既有内容宽度分级：>=1040四列、720–1039两列、<720一列，日期范围可跨两列。模块标题与筛选字段标题不同；不为了本规则批量删除独立业务模块标题，也不额外给简单筛选条加“筛选条件”标题。

## 可访问名称与作用域

- 隐藏的是可见的外部标题，不能删除字段的程序化名称。保留 visually-hidden label、label/for 或 aria-label；开始和结束日期独立命名，范围组用 div/role=group，不用一个label包住两个输入框。
- 选值、清空、加载、禁用、错误、只读及高级筛选展开/收起后，字段语义仍可识别；错误信息继续与对应控件关联。框内底文不能成为唯一可访问名称。
- 不写全局隐藏label、span、input、select的样式，不改壳层或所有表单的默认布局。对项目已有 FilterField 显式传 layout="placeholder"；已有 PointsSelect 只在目标筛选区启用 inline-label。默认 stacked/inset 和普通业务表单保持原样。

## PM 使用方式与参考实现

先检查目标项目已验证组件，优先复用。项目中的 FilterField/PointsSelect 与 Skill 中 FormControl 是映射关系，不应因文件名不同重写全套页面。

Skill参考库中的 FilterBar 为后代 FormControl 提供placeholder布局上下文；FormControl 在普通表单内默认仍为stacked，也支持显式 labelLayout="placeholder"。因此PM复用 FilterBar + FormControl 即得到本合同，字段不能另外叠加上置label。例子见 content-slot-vue-library.md。参考实现是无业务依赖基线，不表示线上或所有项目已迁移。

## 验收

1. 空值、选值、清空和高级筛选展开后均不出现控件上方标题；默认选项不重复字段名，日期底文能区分起止。
2. 运行页面测量：控件与查询/重置按钮36px、字号13px、圆角8px；不能只看源码token。原有focus/disabled/error状态及筛选值保持。
3. 目标筛选区外至少检查一个业务录入表单或新增弹窗：上置标签仍可见。核对全局CSS没有新隐藏标签选择器，共享组件的默认消费者不变。
4. 检查支持桌面宽度及Agent挤压后的换行、局部表格滚动；若未实际测量，不声明全面响应式通过。
5. 新增或修改内容槽文件运行设计guard及适当工程检查，分别记录本地结果、未覆盖状态和生产验收边界。
