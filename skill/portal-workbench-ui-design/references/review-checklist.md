# 交付前评审清单

## 1. Token

- [ ] 本次设计使用项目内 `lexiang-workbench/skill/portal-workbench-ui-design/` 作为唯一规范源，没有引用桌面旧副本或其他平行规范。
- [ ] 颜色全走 `--color-*` 语义变量，无规范外硬编码色。
- [ ] 字号来自字号阶梯；正文 14px，表格 / 表单 13px。
- [ ] 间距使用 4px 基准 Token。
- [ ] 控件高度走 `--control-height-*`。
- [ ] 圆角、阴影、层级、动效使用统一 Token。

## 2. 品牌与字体

- [ ] Logo 未变色、未拉伸、未裁切。
- [ ] 深浅背景使用正确 Logo 版本。
- [ ] 侧栏展开 / 收起态 Logo 形态合理。
- [ ] 字体栈符合 `typography.md`，技术内容使用等宽字体。

## 3. 布局

- [ ] 对所有旧项目已有页面做逐页对比：页面 ID、标题、导航激活、内容区主要结构、KPI / 表格 / Tabs / 筛选数量与旧项目一致；差异只能来自明确保留的新功能。
- [ ] 使用统一 App Shell。
- [ ] 页面已归入一个明确页型模板。
- [ ] 内容区最大宽、内边距、栅格与间距节奏正确。
- [ ] 页面模块间距遵守 `18px` section gap、`16px` module gap、`20px` card inner padding；筛选区、表格、详情卡之间有明确分隔，不贴边、不重叠。
- [ ] 每页都有统一页头：标题、描述、主操作。
- [ ] 所有需要横向对齐的卡片、表格、图表在同一行顶部一致、等高一致。
- [ ] 所有需要纵向对齐的标题、按钮、筛选器、表格列、图表容器在同一基线上。
- [ ] 模块标题保持左上角横排展示；当筛选器/按钮放不下时，控件换到下一行，标题没有被压缩成竖排或错位。
- [ ] 模块标题区满足双边对齐：标题组贴左，说明 / 筛选 / `问 AI` / 操作按钮贴右；换行时操作组整体换行，不漂浮在中间。
- [ ] 标题文字、竖线 / 圆点装饰、标签、右侧按钮在同一视觉中线，装饰点线没有偏上或偏下。
- [ ] 多行标题区的装饰线 / 圆点锚定第一行标题，不按整个 header 高度居中。
- [ ] Grid 子项没有用额外 `margin-top` 造成错位，间距由 grid gap 或统一 section spacing 控制。
- [ ] 侧栏展开态每个父级目录单行展示；chevron 收起向右、展开向下；独立业务域已拆分为独立父级目录。

## 4. 组件

- [ ] 按钮层级清晰，一个页面通常只有一个主按钮。
- [ ] 按钮、图标按钮、Tab、筛选 pill 高度稳定，文字不变形、不挤压、不意外换行。
- [ ] 按钮 / chip / 时间范围 pill 同组间距一致：图文 6px，同组 8px，横向内边距 12px；不用临时空格或随意 margin 修正位置。
- [ ] 表单标签在上，错误提示清晰。
- [ ] 表格有加载、空、错误状态。
- [ ] 状态标签同状态全站同色。
- [ ] 危险操作有二次确认。
- [ ] Toast、Alert、Modal、Drawer 符合组件规范。
- [ ] 图表卡与表格卡同排时，内容区自适应且不空旷；图表已在布局变化后重新计算尺寸。
- [ ] 图表颜色使用单色阶或协调中低饱和色板，类别辨识度足够，同一语义跨图表颜色一致，强红只用于真实警示状态。
- [ ] 全站中间数据展示区的页面顶部 KPI / 主要数据卡片使用基于主色推导的蓝、青、靛、紫四种极浅辅助渐变循环，有色辅助色 alpha 低于 10%（推荐 2.5%-8%），白色收尾可为 100%，颜色有很轻的信息感但不明显抢眼；下方链路步骤 / 拆解项 / 二级统计块 / 图表容器 / 表格容器 / 筛选区 / 待接口占位块保持白底；未使用普通分类浅红、语义 wash、重复标签圆点、左侧色条或顶部色条。
- [ ] 本次样式调整已覆盖所有相关业务模块，不只覆盖“乐享运营”或某一个示例页面。
- [ ] Tabs 选中态只使用文字色 + 下划线，不使用整块背景高亮；Tabs 和筛选区有明确间距，不贴边、不重叠、不靠临时内联样式撑开。
- [ ] Tabs 点击后能切换 active 状态和内容面板，不存在“只显示 tab 样式但点击无反应”的静态 tab。
- [ ] Tabs 的点击逻辑切换标准 `.active` class，并清理冲突内联样式；不是仅修改 `style.color` 或下边框颜色。
- [ ] 描边线框型模块 / chip / 次按钮在 hover 或 selected 时使用主色描边和轻微主色外环；页面级 Tab 不套用描边选中态。
- [ ] 中间数据区域所有卡片 / 面板 / 图表卡 / 表格容器 / 链路节点 / 占位卡使用统一轻量 hover：主色浅描边、轻阴影、`translateY(-1px)`、`.14s` 过渡；AI 面板、按钮、Tab、表格行和输入框未误套用该效果。
- [ ] 联动筛选型指标卡（如 `认证方式分布`）有 hover、focus、selected、清除状态，使用 `aria-pressed`，点击后下方列表/表格确实同步变化，并在列表标题行显示当前筛选条件。
- [ ] 筛选 chip / 时间范围 / 分段按钮在亮色和暗色下均可读：选中态主色底白字，未选中和禁用态对比清晰。
- [ ] 页面顶部筛选按钮、时间范围、上传/刷新/下载等操作保持单行，不出现按钮文字换行；自定义日期范围使用浮层或等价不挤压布局的方案。
- [ ] 日期时间输入和下拉选择器全站统一 36px 高度、10px 圆角、白底细边框、主色 focus 外环，没有内外双重重边框。
- [ ] `AI 解读` / `问 AI` 按钮带小 icon 和主色浅渐变重点样式，不与普通次级按钮混同。
- [ ] 图标按钮 tooltip 在顶栏、AI 面板头部、输入区、抽屉内均可见，不被 overflow 或边界裁切。
- [ ] 下拉菜单、日期时间选择器、筛选 Popover 的圆角、边框、阴影、hover 和选中态符合组件规范。

## 5. 乐享项目专项

- [ ] 左侧导航顺序、父级目录、子菜单、SVG 图标体系、chevron 展开逻辑与本地旧项目一致；新增入口不得插入或打乱旧业务导航。
- [ ] 当前确认版左侧导航不展示 `首页` 父级目录；点击左上 Logo 可回到门户首页，面包屑和 AI 助手关注胶囊可同步到 `首页 / 门户工作台`。
- [ ] 门户首页本期不展示 `今日工作流 / 核心域联动` 面板；四张能力卡、常用入口和流程卡保持白底/细边框/轻 hover 风格。
- [ ] 旧项目已有页面的中间数据区使用旧项目渲染器或等价 DOM 结构；新增功能页面使用旧页面组件拼装，不单独发明一套卡片/表格/图标风格。
- [ ] 右侧 AI 助手使用旧项目完整交互：历史会话、范围标签横向滚动/下拉、附件、发送、欢迎态、结构化回复、继续执行动作和当前页面关注胶囊。
- [ ] API Key 默认掩码并提供复制操作。
- [ ] ID / Key / 数字 / 日志 / JSON 使用等宽字体。
- [ ] 日志级别颜色统一。
- [ ] 配额接近上限使用 warning，满额或失败使用 danger。
- [ ] 复杂创建流程使用 Steps / Wizard。
- [ ] AI 助手默认宽度为 `380px`；支持拖拽扩宽，最大 `492px`，到达最大时只自动收起由 AI 触发的左侧导航，往回拖恢复；头部开关、标签区、输入区、附件和发送按钮符合右侧助手规范；快捷标签位于输入区上方且最多两行。
- [ ] 左侧导航顶部、中间区顶部、AI 区顶部高度一致；AI 助手头部关注胶囊与当前左侧导航二级标题同步，不硬编码某个页面名，也不拼接父级目录。
- [ ] AI 助手头部保留 4 个 icon-only 操作，顺序为 管理技能 / 新开会话 / 历史对话 / 收起 AI 助手，第三个是历史对话。
- [ ] AI 助手默认态为互动文档流欢迎语：`你好！我是乐享 AI 助手。...`，并只展示紧凑推荐问题卡；不出现本期不上线的今日速览、指标卡、异常卡或最近对话。
- [ ] AI 长篇数据 / 解读报告只在右侧显示统一结论卡片，不把全文堆在 AI 面板；点击 `展开查看` 后在面包屑下方出现临时页签，完整报告渲染到中间内容槽，且支持保存、关闭、多开对比和返回当前导航页面。
- [ ] 客户留言和线索管理已作为独立业务目录进入侧栏，页面功能点未丢失，列表、抽屉、筛选、操作状态齐全。
