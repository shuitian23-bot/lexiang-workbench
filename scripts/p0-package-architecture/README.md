# P0 前端包边界

本目录定义 P0 的稳定源码所有权边界：22 个页面包、24 个弹窗/轻提示包，以及 `common`、`agent-content` 两个共享包。每个业务包都有独立 CSS/JS 入口；当前构建仍按 `p0-home-manifest.json` 的既有顺序汇总历史源文件，以保证生产输出字节、加载地址、执行顺序和视觉效果不变。

`public/leaip0` 只保留浏览器实际需要的运行文件。历史源文件位于 `scripts/p0-source-runtime/leaip0`，不能直接发布，也不能被 HTML 引用。

`agent-content` 同时服务全屏和左右分屏。后续把历史源逐项归入包入口时，必须保持：容器宽度适配、重复挂载幂等、事件委托、流式追加、全屏/分屏状态同步，以及现有业务 API 和 DOM 钩子兼容。

弹窗公共能力（遮罩、层级、滚动锁、焦点、ESC、关闭、输入错误高亮）归 `common`；各弹窗入口只拥有自己的结构、字段、状态和业务事件。`toast` 保留包边界，但按当前产品决定默认不启用。
