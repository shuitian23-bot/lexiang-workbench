# 1009 UI 兼容合入

执行基线为已合并 PR #26 的 main `67253c8c7e9328e3bb8776dd1aa6581c499e30eb`，实施期间快进到仅归档上次发布产物的 `ceb0b9e21122e49bed65bdb3e806f99d2683b667`；两者 Vue 源码相同。用户提供的 `lexiang-new-1009.zip` 基于今早 `fe901576` 脱敏交付包修改；只选择包内真正的 UI 增量，未整包替换。

本轮采用的视觉与交互规则来自附件 1009 补充：列表页签计数同基线括号文本、指标卡既有渐变、积分统计层次、Skill Hub 专项页签和创建图标、场景编排全屏与拖线缩放、调整日志窄屏布局。全屏属于编排区专注显示，退出恢复原侧栏和 Agent 状态；普通滚动不被缩放逻辑拦截。

保留当前账号启用公开路由、共享申请组件、首次访问与权限移除流程、本机管理员预填限制、完整审批历史以及“历史已通过启用不被重复申请撤销”的修复。场景包领域和存储模块不变：创建与编辑权限、原创建人、账号切换校验、固定版本、试运行门禁、禁止自审和草稿冲突规则继续以主线实现为准。

独立创建页签与主线缓存行为做兼容：保存和提审返回真实列表实例并定位结果；取消保留原列表筛选并恢复创建按钮焦点；未结束的创建在页签切换时保留。结束创建时先重置再离开；试运行标题绑定当前表单的 DOM 引用，避免隐藏缓存切换账号时失去 Teleport 目标。

UI 包携带的旧登录/权限页面、旧工程配置、旧守卫实现与重复 Skill 分发资源未覆盖主线。本轮使用现有设计检查入口；1009 的明确界面规则优先于 0914 中被本轮更新的局部外观，其他壳层和业务规范保持。没有替换完整历史 Skill 目录，也不把包内的历史验收记录冒充本项目本次验收。

环境状态由 `workbench-ui1009-compatible-20261009` 发布台账分别记录。先发布 new，正式环境需本轮预览确认；发布仅涉及构建入口和 assets，完整 admin-runtime 保留。
