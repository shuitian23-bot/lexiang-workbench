# 个人及家庭原版场景 Banner 集成

基线：2026-08-31 从 p0.leaibot.cn 的服务器获取，禁止以本地整站覆盖。
来源：用户提供 scene-banner.html。完整文件 SHA256 见 source-manifest.json。

| 项目 | 处理 | 验收 |
|---|---|---|
| HTML / CSS / 图像 / 原 JS | 原文件逐字节复用；独立文档隔离样式 | 原文件 SHA256 一致 |
| 六场景按钮 | 原点击选中、标签更新，不擅自联动轮播 | 6 个选中状态 |
| 三张轮播 | 原上一张/下一张、循环、文案、商品标注、自适应深浅控制栏 | 1→2→3→1、反向循环 |
| 配件卡 | 原独立选中、悬停 | 选中互斥，轮播不重置选中 |
| CTA | 业务适配器复用现有 __lxAgentAPI.openProduct | 商品详情打开、返回后 banner 恢复 |
| PC 侧栏尺寸 | 整体等比缩放完整原文档，桌面画布最小1280px；不改组件CSS | 无裁切、无页面横向滚动 |
| 非 banner 模块 | 不改共享 JS/CSS/左助手/商品楼层/其他频道 | 线上差异仅入口新增脚本与新组件 |

交互边界：原示例配件为示例价格，原有标签独立于轮播，均保留。HTML 内 CTA 无处理函数；集成延续现有线上三商品入口，按游戏本/平板/创作本重排。
发布：服务器独立 Git 工作区基于线上 HEAD 修改；发布前检测实时差异，Git 合并，不上传整页。回滚移除入口新增脚本即可，原场景完整保留且组件加载失败时继续显示。
