# 企业客户与订单菜单新增设计

## 目标

在当前门户工作台基线上新增两个可用入口，同时保留全部既有菜单与功能：

- 企业客户管理新增“线索池-政企”。
- 订单管理保留“协议采购单管理”，新增“协议产品订单管理”。

## 范围

本次只调整以上两个一级菜单下的菜单配置、路由、页面入口及其直接依赖的页面运行逻辑。不得引入压缩包中与本次无关的 Agent、Skill、权限管理、打分模型、公共样式、登录或其他业务模块变化。

## 方案

1. 在 `MENU_TREE` 中按现有顺序新增两个二级菜单项，不删除或重命名已有菜单。
2. 为两个新页面增加独立 Vue 路由包装组件。
3. “协议产品订单管理”使用独立运行脚本，避免影响现有协议采购单页面。
4. “线索池-政企”只把压缩包内政企线索所需的渲染、筛选、只读详情和导出逻辑移植到当前线索运行脚本；不带入同一文件中的打分模型等其他差异。
5. 详情页继续使用工作台现有隐藏路由机制，不增加左侧菜单项。

## 保护范围

- 保留 `order.purchaseOrders` 及其现有路由和页面源码。
- 不修改 `workbench-geo.js`、`workbench-pages.js`。
- 不替换整个 `workbench-lead.js`，只应用政企线索相关的小范围补丁。
- 不部署 `new`、正式环境，也不推送 Git，除非用户后续分别确认。

## 验收

- 左侧企业客户管理包含“线索池-政企”，原三个菜单仍在。
- 左侧订单管理同时包含“协议采购单管理”和“协议产品订单管理”。
- 两个新入口可打开，新订单详情可进入和返回。
- 原协议采购单路由仍可访问。
- 产品契约、类型检查、Lint、构建和工作台冒烟检查通过。
