# 场景技能包创建与拖拽编排

用户授权更新场景技能包创建：必填项先填入可编辑示例；原第 2、3 步合并，将分类 Skill 拖到操作区后配置执行链路和判断条件。

## 页面合同

沿用当前 new 的 22be80e6 Vue 源码、0818 组件与样式规范，T4 业务表单叠加 V2 专项创建流程。流程为场景定义、Skill 链路编排、权限和版本评估、管理员审批发布四步。场景定义示例以职场人群认证经营管理为主题，不预选 Skill，不预选责任人确认。

新增页面局部 ScenarioSkillPackageComposer，复用 SectionHeader 与现有 Pinia/domain 数据。用户补充 https://teamx-aiwork-report.dockeruat.lefile.cn/ 作为交互参考，已在其打开的 Chrome 工作流编辑器只读核验节点库、网格画布、箭头依赖及右侧属性栏。页面采用左侧分类 Skill 库、中间自由布局画布、右侧节点或连线配置，沿用门户浅色样式。

Skill 拖入时在落点新增未连接节点；重复拖入选中已有节点。节点可拖动位置，从输出端口拖到输入端口建立连接，也可点击端口或选择前序节点。连线决定执行顺序，位置仅决定画布排布；不显示上移、下移按钮。支持断开连接、移除节点、缩放和整理布局，画布内部滚动，不产生页面横向溢出。按内容宽度调整分类库和配置栏布局，保留键盘操作与删除后的焦点恢复。

## 链路兼容规则

步骤新增可选 predecessorId 和 position。旧记录没有 predecessorId 时按原数组顺序解释；进入编辑后显式保留连接关系。新节点 predecessorId 为 null，连接全部节点形成单条顺序链后允许评估与发布。自连、循环、悬空依赖、多后继及断开节点在统一 domain 入口阻断，最终发布与运行再次校验，不用数组位置猜测未连好的链路。

固定版本及权限快照保持不变；条件仍是节点执行条件，满足执行、不满足跳过后继续，由现有运行入口选择条件步骤，不增加并行、互斥分支或条件表达式执行引擎。位置与连接关系随已发布快照深拷贝保留。新组件 scoped 样式，不修改壳层、权限模块与受保护 runtime。

执行前确认与审批均为选填，默认都不勾选，允许不选任何一项直接继续；页面明确显示选填及执行时仍需校验权限的说明。仅勾选相应选项时要求对应执行凭据，保留现有权限与发布门禁，不新增风险策略或真实执行服务。

场景定义按 0818 的 T4 表单与 V2 专项工作区统一：外层页头、数字文字步骤导航与底部操作占满内容槽，步骤、白底正文和操作区连接为同一个工作区。正文最大宽度 720px，居中单列，使用共享 SectionHeader，字段间距 20px、标签到控件 8px；输入框 36px、文本域至少 88px，白底与 400 字重，主责任人保持只读底色。必填使用红星、文字和 required 语义。底部流程按钮整体靠右且不随正文滚走；窄槽允许步骤文字换行，正文独立滚动。保留 mock、前进返回、确认选填和链路逻辑，不改画布组件及权限模型。

## 验收

场景定义与 Skill 链路编排共用白底工作区外层，步骤导航、正文和底部操作边框连续；仅编排画布内部保留浅灰点阵底。页面级浅色背景不得透入编排区的标题、列间空隙与下方留白。此补充只影响第 2 步外层表面，不调整画布与节点交互。

验证可编辑预填、四步前进/返回、拖入落点与移动、端口连线与断开、连接顺序与布局分离、无效链及缺失条件拦截、重复拖入、配置保留、权限版本重评估、确认重置。模型测试覆盖旧记录兼容、乱序链、环路/分叉/断开/悬空依赖、快照隔离与发布/运行门禁。浏览器核验画布、配置、Agent 挤压后的可用性。工程执行 Node 回归、设计 guard、lint、typecheck、build、shell smoke。

发布仅更新 new；用 Git 预览分支进入个人服务器工作区构建，备份、增量资源与原子入口切换、保留 runtime，登记实际发布人/时间/版本。正式和 GitLab 独立报告。
