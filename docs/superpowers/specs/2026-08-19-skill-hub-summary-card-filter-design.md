# Skill Hub 汇总卡筛选设计

## 目标

Skill Hub 顶部六张汇总卡全部成为下方 Skill 列表的筛选入口，筛选结果与卡片显示数量使用同一口径。

## 交互

- “全部 Skill”展示全部记录并作为默认选中项。
- “我的 Skill”筛选当前账号拥有的记录。
- “待审批”筛选主状态或编辑版本状态为待审批的记录。
- “已发布”筛选存在上线版本且未禁用的记录。
- “能力更新”筛选当前存在可处理能力变化的记录。
- “已禁用”筛选主状态为已禁用的记录。
- 点击非当前卡切换筛选；再次点击当前非全部卡恢复“全部 Skill”。
- 点击汇总卡时清空关键词、状态和分类，避免多个入口叠加后无法理解结果。
- 所有卡片使用真实按钮、`aria-pressed` 和既有 `is-active` 样式。

## 保护范围

- 不调整 Skill 操作列、审批发布流程、能力更新状态机和表格字段。
- 不修改公共导航、AI 助手、权限管理或 `admin-runtime`。
- 只更新 `new` 预览；正式环境与 GitLab 仍需单独确认。

## 验收

- 六张卡均可点击且只有当前筛选卡显示选中态。
- 每种筛选的列表数量与卡片数字一致。
- “只看有更新”开关与“能力更新”卡保持同步。
- 54 项现有契约测试及新增筛选测试通过，构建和壳层冒烟通过。
