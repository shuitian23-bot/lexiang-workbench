# Skill 创建能力提示增加名称

## 目标

Skill 创建页左侧能力卡片的悬停提示同时展示能力名称和能力描述，帮助用户确认当前提示对应的能力。

## 展示规则

- 第一行展示能力名称并加粗，例如“流量分析”。
- 第二行展示现有能力描述。
- 提示宽度和定位沿用当前规则，允许描述自然换行。
- 鼠标悬停和键盘聚焦均展示相同内容。
- `aria-describedby` 继续指向同一个提示节点。

## 保护范围

本次只调整 `AgentSkillCreateView.vue` 内能力卡片提示的数据、模板和局部样式，不修改：

- 能力卡片正文和尺寸；
- 能力搜索、筛选、选择及移除逻辑；
- Skill 创建步骤、表单、状态和提交逻辑；
- Skill Hub、权限管理、右侧 AI 助手；
- `admin-runtime` 及其他页面。

## 验证

- 悬停“流量分析”时，提示第一行显示“流量分析”，第二行显示对应描述。
- 键盘聚焦能力卡片时展示相同提示。
- 移出或失焦后提示关闭。
- 现有能力选择、筛选和创建流程保持不变。
- 增加源码回归断言，并执行代码检查、类型检查和生产构建。
