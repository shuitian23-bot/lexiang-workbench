# 技能包个人赞踩

用户已确认：技能包管理中每张卡片的使用次数旁增加赞、踩；二选一，再点当前选择取消；保存个人选择，不展示累计数量。

选择按当前已登录工作台账号、当前站点浏览器、技能标识隔离保存在 localStorage。刷新及弹窗重开恢复；不跨设备或 new/正式域名同步，不产生团队统计。未登录时不可反馈；存储失败维持原状态并提示重试，不虚报成功。

复用回答反馈的线性 SVG、主题色和键盘按钮。保留次数、启停、搜索、筛选、卡片顺序及权限逻辑。通过现有 legacy adapter 观察实际弹窗卡片，Vue Teleport 渲染反馈控件，不覆盖 protected runtime。优先使用卡片已有 skill ID/name；旧卡片无 ID 时沿用旧渲染器的技能标题身份。同一技能重复展示共享选择，不同显式 ID 即使同名也独立。DOM 挂载身份独立于反馈身份，卡片脚部重绘后恢复控件。不得按索引或使用次数生成反馈标识。

验收：单个技能互斥与取消、不同技能/账号隔离、刷新/重开恢复、存储异常、无累计数量、开启/关闭/搜索原行为、动态任意数量卡片、1280/1440 布局与键盘操作。仅发布 new，正式保持当前已验收版本。
