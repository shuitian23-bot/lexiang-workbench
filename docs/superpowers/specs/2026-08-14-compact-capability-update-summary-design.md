# 能力更新摘要下移设计

## 目标

移除 Skill 创建页标题下方的整条“能力上下文变化”横幅，让页面标题后直接进入 Skill Workspace，减少顶部空间占用。

## 布局

- 删除页面级 `skill-capability-update-banner`。
- 在需求澄清页已有“能力上下文”模块标题区内增加紧凑变化摘要。
- 摘要保留：已选能力受影响数、可选新增数、目标能力版本和检测时间。
- 删除顶部“查看能力上下文”按钮；保留左侧能力卡定位下方模块所需的内部聚焦函数。
- 无能力变化时不展示变化摘要，原能力上下文内容保持不变。

## 验证

- 页面级横幅和对应样式不存在。
- 变化摘要位于 `skill-capability-context-panel` 内。
- 1280px 和常规宽屏下标题区不挤压、不溢出。
- 既有能力选择、加入上下文和更新草稿流程保持可用。
