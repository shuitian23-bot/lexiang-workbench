# 普通试运行混合数据样例 Implementation Plan

**Goal:** 普通拖入并连接节点后，开始试运行即可展示一个正确和一个不正确的模拟反馈，按提示修正后重跑成功。

**Architecture:** Create.currentDraft 在执行副本中为空任务解析同固定已发布 Skill 的说明，输入框继续保留空值和提示，提交保存实际执行任务。Trial 默认使用 mixed-feedback 样例请求；固定版本的第二个实际执行节点在预期输出未补充时返回不完整的数据样例，失败反馈不传给下游。补充该节点预期输出后重跑正常，不按次数自动通过。模拟结果与请求保留模式，提交 gate 检查同一负样例规则。

**Scope:** 场景包创建/试运行与样例数据，保留权限、依赖、未知版本和自审防护；普通 Skill 管理与权限管理不改。

- [x] 新增普通拖入两节点的真实 Vue/Pinia 流程测试与混合样例 domain 测试，观察失败后实现。
- [x] 实现有效任务执行副本、默认混合反馈请求及具体正负样例；失败保留不完整输出与建议。
- [x] 更新旧空任务演示为数据错误演示，验证未修仍错、修改后过期、重跑恢复及提交快照有效任务。
- [ ] 执行工程与浏览器验证，只发布 new，保留正式站与 admin-runtime，并归档证据。

验证：260 项场景回归、设计检查、lint、类型检查、构建与页面交互通过；浏览器普通添加产品知识问答和认证查询，验证一成功一失败、未修改重跑仍失败、返修保留提示、补预期输出后重跑双成功且可进入提交页。三节点失败反馈不传给下游。发布状态见交付记录。
