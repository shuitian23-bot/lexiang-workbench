# 可重复试运行示例 Implementation Plan

**Goal:** 新建场景包的空白画布可显式载入“一节点成功、一节点失败”的示例，补全失败节点后重跑成功。

**Architecture:** Composer 增加仅由新建可编辑 CreateView 开启的空画布入口。使用当前目录的职场认证状态查询 v1.0.0 与职场人群经营分析 v1.2.0，保存真实固定版本和权限快照；示例节点已连线，第一任务完整，第二任务为空。不改变通用模拟运行器和审核门禁。

**Acceptance:** 相同配置连续运行都显示第一节点成功、第二节点失败并给出任务填写建议；返回修改定位第二节点且保留提示。填写第二任务后旧结果过期，重新试运行两个节点成功，反馈传递正常，可直接提交待审核。每次新建空白场景都可重复体验；既有编排或草稿不覆盖，普通拖入节点仍不预填任务。

- [x] 添加 loadTrialExample 与 canLoadTrialExample，空白且授权时显示入口；Skill 或版本不可用时隐藏入口并阻止加载。沿用原有按钮样式和输入布局。
- [x] 完成失败—返回—修改—重跑成功的浏览器验证及工程检查，更新同一调整日志。
