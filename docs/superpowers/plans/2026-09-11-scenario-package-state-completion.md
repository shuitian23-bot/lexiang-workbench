# 场景技能包状态缺项补齐实施计划

> 用户已审阅状态核查结论，并明确要求“补齐对应的POC”。本计划执行该范围，无需重新讨论或扩充状态。

**目标：** 补齐草稿保存、升级操作提示、可恢复依赖的状态刷新及暂停示例试运行样例。

**实现：** 复用现有 T4 表单及四步流程、Skill Hub 列表和状态权限判断。保存使用场景包专用本地存储，旧审核快照与待编辑内容分离。依赖是否恢复由当前目录及固定版本决定。所有状态仍按已核查矩阵提供动作。

**技术：** Vue 3、Pinia、现有 Node 测试与 Vite，不增加依赖。

## 约束

- 本人待审核只有详情，不可自审、编辑或撤回；其他管理员不能代编辑。
- 审核后发布，原禁用版本保持禁用，不加额外发布阶段。
- 已保存的新内容不替换旧审核版本；保存无需完成全部配置，提交必须重新通过试运行与现有权限、版本、链路校验。
- 保存包名必填；保存失败保留输入及当前记录；保存成功返回列表，可重新编辑并刷新恢复。
- 仅场景包本地状态持久化；不修改权限管理、其他模块及通用组件。产品调整日志按发布规范维护。
- 固定版本真正过期、当前目录缺失或禁用仍阻断；不得用新的可用版本冒充旧固定版本。
- 首次一成功一失败、返回修改后重试成功的既有演示保留；未知 Skill 版本无样例仍报错。
- 更新 new 预览，正式环境不更新。通过 Git 传递源码，不覆盖受保护运行文件。
